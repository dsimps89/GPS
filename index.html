Historical calibration uses only saved entries with actual counts, in the same activity domain. It adjusts aggregate scale, not the underlying movement of individuals.

Crime/justice and medical views model aggregate service demand only, not crimes, diagnoses, individual risk, or patient locations.

Immutable calendar archive · JSON database

Give each entry a title, select a past, present, or future date, and save the current model prediction. Optionally enter an aggregate observed count. Once saved, an entry cannot be edited or deleted in this interface. To add a later observation, create a new titled entry referencing the earlier one.

Save limits: at least 25 minutes between entries, and no more than 10 saved entries in any rolling 24 hours, enforced in this browser. Imported records are deduplicated by ID; import does not count as a new observation. Export JSON for durable backup.
